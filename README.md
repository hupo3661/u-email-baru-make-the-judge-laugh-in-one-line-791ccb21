Entry for the make.fun competition
[u-email-baru-make-the-judge-laugh-in-one-line-791ccb21](https://make.fun/c/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21):
one funny line, up to 200 characters, on any topic.

## The line

> My smart fridge emailed me a diet plan, then left its own door open all night like the calories were my problem.

(112 characters, one sentence. Also saved in `entry.txt`.)

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it. The program
checks the line is non-empty, a single sentence, and at most 200
characters, then reads the file back to verify it matches.
